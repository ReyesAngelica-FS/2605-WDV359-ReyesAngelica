# Ala Rey Studios

## Overview
Ala Rey Studios is a luxury event planning and creative portfolio website focused on elegant celebrations, curated event experiences, and modern branding.

## Features
- Multi-page React application
- Responsive homepage layout
- Gallery preview sections
- Event album categories
- About page
- Services page
- Contact page
- Social media footer integration
- Responsive styling

## Tech Stack
- React
- Vite
- JavaScript
- CSS
- React Router
- React Icons

## Future Development
Future development plans include:
- Node.js backend integration
- Express API functionality
- MongoDB database integration
- Inquiry form submissions
- Booking management
- Dynamic gallery management

npm run dev
