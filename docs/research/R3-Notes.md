# Topic – Innovation, Security, and Strategic Planning

This week’s research focused on innovation, security awareness, and strategic analysis for Ala Rey Studios. I explored SWOT analysis, OWASP web security risks, GitHub security scanning tools, and creative innovation practices that can help strengthen both the user experience and long-term development process of my project.

I also researched real-world portfolio and event-planning websites to better understand how professional businesses structure their branding, security, user experience, and client interaction systems.

---

# Sub-Topic 1 – SWOT Analysis

A SWOT analysis helps identify strengths, weaknesses, opportunities, and threats related to a project or business idea.

## Strengths
- Clean and modern portfolio-style design
- Strong focus on branding and user experience
- Mobile-friendly design approach
- Personalized and creative event-planning concept

### Real Website Comparison
Websites like HoneyBook and The Knot use clean layouts, strong branding, and simplified navigation to guide users toward booking services and exploring galleries. These sites helped inspire the importance of keeping Ala Rey Studios visually clean and easy to navigate.

---

## Weaknesses
- Project is still early in development
- Limited backend functionality currently implemented
- Requires continued UI refinement and responsive testing

### Real Website Comparison
Compared to larger professional platforms like Squarespace or Wix, Ala Rey Studios currently lacks advanced integrations such as scheduling systems, CMS tools, and client dashboards. This comparison helped me recognize areas that may need future development.

---

## Opportunities
- Ability to integrate booking and inquiry forms
- Opportunity to expand into WordPress integration later
- Potential for gallery filtering and client management tools
- Ability to integrate analytics to understand user engagement

### Real Website Comparison
Creative portfolio websites like Pixieset and Showit demonstrate how galleries, inquiry forms, and client experiences can improve engagement and professionalism. These features could eventually strengthen Ala Rey Studios and improve the client experience.

---

## Threats
- Security vulnerabilities from outdated dependencies
- Poor mobile optimization affecting usability
- Competition from other event-planning websites
- Scope creep during development

### Real Website Comparison
Large service-based platforms continuously update their websites to improve security and mobile responsiveness. Sites that load slowly or are poorly optimized often create frustrating user experiences, which can cause users to leave quickly. This reinforced the importance of responsive testing and dependency maintenance during development.

---

### Key Findings
Performing a SWOT analysis helped me better understand how to strategically plan development priorities while also identifying future risks and growth opportunities.

# Sub-Topic 2 – OWASP Top 10 Web Security Risks

The OWASP Top 10 highlights the most common and dangerous security vulnerabilities in web applications.

## Important Risks Relevant to My Project
- Broken Access Control
- Security Misconfiguration
- Vulnerable and Outdated Components
- Injection Attacks
- Identification and Authentication Failures

---

## How This Applies to Ala Rey Studios

As Ala Rey Studios grows, especially if inquiry forms or user authentication are added later, security practices will become increasingly important. Keeping dependencies updated, validating user input, and protecting sensitive data are critical steps in maintaining a secure application.

### Real Website Comparison
Modern business websites frequently use secure forms, HTTPS encryption, spam protection, and authentication systems to protect user information. Platforms such as WordPress and Shopify regularly release security updates to reduce vulnerabilities and improve protection for websites using their services.

---

### Key Findings
Security should be considered early in development instead of being added later. Even portfolio-style applications can become vulnerable if proper practices are ignored.

# Sub-Topic 3 – Code Scanning & Development Tools

GitHub CodeQL and similar tools can automatically scan projects for vulnerabilities, coding errors, and dependency risks.

## Tools Researched
- GitHub CodeQL
- Dependabot
- Snyk
- npm audit

---

## How These Tools Help
- Detect outdated packages
- Identify security vulnerabilities
- Improve code quality
- Reduce deployment risks

### Real Website Comparison
Many professional development teams use automated tools to improve software reliability. GitHub’s built-in security tools and services like Snyk help developers identify risks before deployment. This type of automated scanning is commonly used in professional environments to improve application stability and security.

---

### Key Findings
Automated scanning tools can help developers catch issues early and improve the stability and security of applications throughout development.
