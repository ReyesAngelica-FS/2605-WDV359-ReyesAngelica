# Project Summary

Ala Rey Studios is a fully responsive portfolio website developed as the capstone project for Full Sail University's Project & Portfolio 6 course. The project showcases modern web development practices using React and Vite while demonstrating the complete software development lifecycle—from planning and design to testing, deployment, documentation, and final client handoff.

The website serves as a professional portfolio for an event planning and creative design business, highlighting services, event galleries, and contact information for prospective clients.

---

# Project Overview

The goal of this project was to design and develop a responsive, visually appealing website that effectively markets Ala Rey Studios' event planning services while providing a professional user experience across desktop and mobile devices.

Throughout development, the project emphasized clean code organization, responsive design, accessibility, search engine optimization (SEO), documentation, and deployment using GitHub Pages.

---

# Project Objectives

- Design a modern and responsive website.

- Create reusable React components.

Several challenges were encountered during development.

Each challenge was addressed through research, testing, debugging, and incremental improvements.

# Lessons Learned

Developing Ala Rey Studios provided valuable experience beyond writing code. Throughout the project, I learned how important planning, organization, testing, deployment, and documentation are to a successful software project.

One of the most valuable lessons was realizing that delivering a website involves much more than completing the code. Preparing documentation, creating a maintenance plan, and organizing a professional handoff packet are essential to ensuring another developer or client can successfully maintain and build upon the project.

This experience also strengthened my confidence using Git, GitHub, React, responsive design principles, and professional development workflows.
