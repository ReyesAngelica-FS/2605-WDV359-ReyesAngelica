# Changelog

All notable changes to the Ala Rey Studios project are documented in this file.

This project follows a milestone-based changelog to summarize major updates completed during development.

---

## [1.0.0] - 2026-07-26
### Added
- Final production release of the Ala Rey Studios website.
- Responsive navigation for desktop and mobile devices.
- Home, About, Services, Gallery, and Contact pages.
- Event showcase galleries for:
  - Weddings
  - Baby Showers
  - Birthdays
  - Private Celebrations
  - Corporate Events
- Hero section and call-to-action buttons.
- Image optimization for faster page loading.
- GitHub Pages deployment.
- Project documentation, including:
  - Maintenance Plan
  - Marketing Plan
  - SEO Plan
  - Analytics Plan
  - Final Handoff Packet

### Changed
- Improved page layouts and spacing.
- Refined color palette and typography for a luxury event-planning theme.
- Updated navigation and footer styling.
- Improved mobile responsiveness across all pages.

### Fixed
- Resolved React Router deployment issue on GitHub Pages by implementing `HashRouter`.
- Corrected Vite deployment base path configuration.
- Fixed image loading and routing issues after deployment.
- Improved component organization and code readability.
