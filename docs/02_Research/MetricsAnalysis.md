# Ala Rey Studios - Metrics & Analysis

This document contains research related to metrics, analytics, user interaction tracking, and testing strategies for Ala Rey Studios. The purpose of this research is to better understand how analytics and testing can improve user experience, strengthen the business case, and support future development decisions.

---

# Business Case Validation

Ala Rey Studios is designed to function as a visually engaging portfolio-style website for creative event planning and themed celebrations. Since the project focuses heavily on branding and visual presentation, understanding user interaction is important for future improvements and business growth.

Metrics and analytics can help validate:
- User engagement
- Navigation flow
- Inquiry form interaction
- Mobile responsiveness
- Gallery popularity
- User behavior patterns

---

# Analytics & User Tracking

Analytics tools can help identify how users interact with Ala Rey Studios and which sections of the site perform best.

### User Engagement

# A/B Testing Opportunities

A/B testing compares two versions of a design element to determine which version performs better for users. This strategy can help improve user interaction, engagement, and overall user experience throughout Ala Rey Studios.

## Potential Testing Areas

### Homepage Hero Section

#### Version A
Large full-screen event image with minimal text.

#### Version B
Smaller featured image with additional branding text and a visible “Book a Consultation” button.

**Purpose:**  
Test which homepage layout keeps users engaged longer and encourages more interaction.

---

### Inquiry / Contact Buttons

#### Version A
Gold “Contact Us” button placed in the top navigation.

#### Version B
Black “Start Planning” button displayed inside the homepage hero section.

**Purpose:**  
Determine which button placement and wording generates more inquiry submissions.

---

### Gallery Layout

#### Version A
Traditional grid-style gallery layout.

#### Version B
Pinterest-style masonry gallery layout.

**Purpose:**  
Compare which gallery structure users browse longer and interact with more frequently.

---

### Navigation Design

#### Version A
Traditional top navigation menu.

#### Version B
Minimal mobile-style hamburger menu.

**Purpose:**  
Evaluate which navigation style improves usability and browsing experience across devices.

---

### Branding & Visual Style

#### Version A
Soft neutral luxury-inspired colors.

#### Version B
Bold modern editorial-inspired colors.

**Purpose:**  
Test which branding direction creates stronger visual engagement and better reflects the Ala Rey Studios identity.

## Potential Testing Areas

### Homepage Layout
- Large imagery vs minimal imagery
- Different hero section layouts

### Navigation Design
- Simplified navigation menus
- CTA button placement

### Gallery Layout
- Grid layout vs masonry layout
- Category organization styles

### Branding Elements
- Typography choices
- Color palette variations
