# Project Overview

Ala Rey Studios is a responsive React-based portfolio website developed to showcase professional event planning and creative design services. The website serves as a digital portfolio where prospective clients can learn about services, browse event galleries, and contact the business.

This project was completed as the capstone for Project & Portfolio 6 at Full Sail University and demonstrates the complete software development lifecycle, including planning, design, development, testing, deployment, documentation, and client handoff.

# Installation Instructions

## Requirements

- Node.js
- npm

Clone the repository.

```bash
git clone https://github.com/ReyesAngelica-FS/2605-WDV359-ReyesAngelica.git
```

Install dependencies.

```bash
npm install
```

Run the development server.

```bash
npm run dev
```

Create a production build.

```bash
npm run build
```

Deploy to GitHub Pages.

```bash
npm run deploy
```

---

# Deployment Instructions

The website is deployed using GitHub Pages.

Deployment process:

1. Verify the project builds successfully.
2. Commit changes to the repository.
3. Push changes to GitHub.
4. Run the deployment script.
5. Verify the live website.
