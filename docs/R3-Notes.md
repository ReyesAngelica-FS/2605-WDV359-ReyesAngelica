# Topic – Innovation, Security, and Strategic Planning

This week’s research focused on innovation, security awareness, and strategic analysis for Ala Rey Studios. I explored SWOT analysis, OWASP web security risks, GitHub security scanning tools, and creative innovation practices that can help strengthen both the user experience and long-term development process of my project.

# Sub-Topic 1 – SWOT Analysis

A SWOT analysis helps identify strengths, weaknesses, opportunities, and threats related to a project or business idea.

## Strengths
- Clean and modern portfolio-style design
- Strong focus on branding and user experience
- Mobile-friendly design approach
- Personalized and creative event-planning concept

## Weaknesses
- Project is still early in development
- Limited backend functionality currently implemented
- Requires continued UI refinement and responsive testing

## Opportunities
- Ability to integrate booking and inquiry forms
- Opportunity to expand into WordPress integration later
- Potential for gallery filtering and client management tools
- Ability to integrate analytics to understand user engagement

## Threats
- Security vulnerabilities from outdated dependencies
- Poor mobile optimization affecting usability
- Competition from other event-planning websites
- Scope creep during development

### Key Findings
Performing a SWOT analysis helped me better understand how to strategically plan development priorities while also identifying future risks and growth opportunities.

# Sub-Topic 2 – OWASP Top 10 Web Security Risks

The OWASP Top 10 highlights the most common and dangerous security vulnerabilities in web applications.

## Important Risks Relevant to My Project
- Broken Access Control
- Security Misconfiguration
- Vulnerable and Outdated Components
- Injection Attacks
- Identification and Authentication Failures

## How This Applies to Ala Rey Studios
As Ala Rey Studios grows, especially if inquiry forms or user authentication are added later, security practices will become increasingly important. Keeping dependencies updated, validating user input, and protecting sensitive data are critical steps in maintaining a secure application.

### Key Findings
Security should be considered early in development instead of being added later. Even portfolio-style applications can become vulnerable if proper practices are ignored.
