# Week 1

## ⚙️ Overview – What I worked on this past week

This week I focused on building the foundation for my Project & Portfolio work and planning my new project, **Ala Rey Studios**. Ala Rey Studios is a modern portfolio-style website for a personal party planner and creative event brand. The goal of the site is to showcase event themes, party styles, creative concepts, and services through a visually engaging layout inspired by photography and lifestyle portfolio websites.

During this week, I setup my new repository using the required naming conventions and established my GitHub workflow structure with `main`, `dev`, and `staging` branches. I also created the required documentation folders, milestone structure, labels, project views, and GitHub issues for ongoing Agile project management.

Additionally, I completed my initial Project Proposal, Tech Stack documentation, and Research Notes covering GitHub workflow, Agile planning, feature branch workflow, and Pull Requests. I also began gathering inspiration for the visual direction and branding style of Ala Rey Studios.

<br>

## 🌵 Challenges – What problems did I have & how I'm addressing them

One challenge this week was deciding on the overall creative direction and structure for the project. Since I wanted Ala Rey Studios to feel modern, elegant, and visually organized, I spent time researching portfolio layouts and event-planning websites to better understand user experience and presentation styles.

Another challenge was making sure my GitHub workflow aligned with course expectations. To address this, I carefully followed the course workflow setup instructions and organized my tasks using milestones, labels, issues, and feature branches to keep development structured and manageable.

<br>

## 🏆 Accomplishments – What I "leveled up" on this week

This week I strengthened my understanding of:
- Agile workflow and GitHub project organization
- Feature branch workflow and Pull Request management
- Repository setup and milestone planning
- Creating professional project documentation
- Structuring a portfolio-style project around a creative business concept

I also successfully established the development foundation for Ala Rey Studios, including documentation, workflow organization, and early project planning.

<br>

## 🔮 Next Steps – What I plan to prioritize and do next

Next week, I plan to begin the visual design and structure phase of Ala Rey Studios. My priorities include:
- Creating wireframes for the homepage, gallery, services, and contact pages
- Researching modern event-planning and portfolio website inspiration
- Building a style guide with branding colors, typography, and UI elements
- Beginning the React front-end structure
- Continuing to organize GitHub issues and update milestone progress
