Ala Rey Studios is a modern portfolio-style website for a personal party planner and creative event brand. The goal of the site is to showcase event themes, party styles, creative concepts, and services through a visually engaging layout inspired by photography and lifestyle portfolio websites.

During this week, I setup my new repository using the required naming conventions and established my GitHub workflow structure with `main`, `dev`, and `staging` branches.
